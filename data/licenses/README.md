# Provenance dan atribusi

Card asli dari revision pinned disimpan oleh downloader. WebSight menggunakan CC-BY-4.0 dan meminta pengungkapan penggunaan ketika merilis model/aplikasi. Sumber gambar atau URL di HTML tidak diunduh dan tidak dijalankan.

- WebSight: Hugo Laurencon, Leo Tronchon, Victor Sanh, 2024. [Dataset](https://huggingface.co/datasets/HuggingFaceM4/WebSight), [technical report](https://arxiv.org/abs/2403.09029), [CC-BY-4.0](https://creativecommons.org/licenses/by/4.0/).
- Vulcan: xlelords, 2026. [Dataset dan pernyataan MIT](https://huggingface.co/datasets/xlelords/vulcan). Card tersimpan; repo sumber tidak menyediakan file LICENSE terpisah pada revision yang digunakan.

Subset JSONL menyimpan revision, license, dan attribution per record. Data besar lokal tidak ikut Git.
