# Output Pipeline

Folder ini berisi ringkasan audit yang kecil serta metrik/visualisasi lokal.

- `dataset_audit/*.json`: ringkasan data sumber yang ditinjau dan dapat dilacak Git.
- `metrics/`: JSONL/CSV loss-step, ringkasan TRAIN ID, dan grafik lokal.
- `sample_images/`: screenshot hasil evaluasi browser setelah aplikasi tersedia.
- Setiap output merujuk RUN ID atau TRAIN ID, commit, config, dan revision dataset.
- Raw dataset dan screenshot sumber tidak disimpan di sini.
