# TRAIN-025 Selected Runtime Bundle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Create a discoverable, provenance-bound local bundle of TRAIN-025 step 1,800 and its selected development output without changing canonical training artifacts.

**Architecture:** A packaging utility reads the frozen development-selection report, resolves and verifies the checkpoint pointer using the existing checkpoint loader, copies the selected pointer and its `.versions` payload together, and copies only the selected development output. It writes a tracked manifest and README while Git ignores the binary and output copies.

**Tech Stack:** Python in the existing project `.venv`, `pathlib`, `shutil`, `hashlib`, existing `src.training.engine` checkpoint helpers, JSON manifests.

**Spec:** `docs/superpowers/specs/2026-10-15-generator-chat-application-design.md`

## Global Constraints

- Select only `TRAIN-025` step `1800` from `reports/training/FULLPAGE-V5_DEVELOPMENT_SELECTION.json`.
- Require the selected report to state `status=passed`, `model_gate_passed=true`, `final_used=false`, 80 of 80 development pages, and `browser_status=pending` plus `human_review_status=pending` in the generation report.
- Verify checkpoint bytes and lineage through `read_checkpoint` or `checkpoint_sha256`; preserve the pointer and referenced `.versions` files as a working relative layout.
- Copy only the development output reported for TRAIN-025. Do not read or copy test or final inputs, outputs, or records.
- Refuse to overwrite any existing package destination or canonical checkpoint/output.
- Add only provenance files to Git. Ignore the copied checkpoint payload and development website output.
- Do not run inference, training, tests, or build checks. Record the package-copy command as an artifact-producing RUN.
- Commit and push each completed change on `feature/pipeline-data-model-training` without a `Co-Authored-By` trailer.

## Review Focus

- A selection report points at a different run, step, checkpoint, request hash, or output. The packager must stop before copying.
- The checkpoint pointer's manifest or payload digest is invalid. The packager must stop and leave no partial package.
- The selected development report says final data was used or has fewer than 80 accepted pages. The packager must refuse selection.
- The package destination already exists. The packager must refuse to overwrite it.
- The output copy contains paths that resolve outside the project. The packager must refuse those paths.
