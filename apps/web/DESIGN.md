# WebCraft UI direction

## Owner brief

- Team: VibeStack
- Project: WebCraft GPT
- Website identity: WebCraft by VibeStack
- Requested direction: contemporary, appealing, and easier to use

## Design read

Reading this as a prompt-to-website workbench for project users, with a warm editorial toolbench style. Dials: ENERGY 2 / RHYTHM 2 / MOTION 1.

The audience and visual language are implementation interpretations of the owner brief. The interface should keep attention on the prompt, factual review, and generated page.

## Visual system

- Surfaces use warm paper and off-white to soften long review sessions.
- Deep pine is the primary action color. Charcoal carries text and terracotta is a restrained brand accent.
- IBM Plex Sans remains the interface typeface for readable controls. IBM Plex Mono remains reserved for code and technical values.
- The Code2 glyph identifies the web-code workbench. It appears in the brand mark without an extra AI badge.
- Navigation keeps chat history, new chat, Usage, and logout. Preview, source, viewport, and ZIP controls remain in the canvas toolbar.
- Cards use a small radius range and mostly flat surfaces. Borders separate work areas; shadows are reserved for controls that need elevation.
- Motion uses short hover, focus, and loading feedback only. No decorative looping animation.

## Interaction priorities

- Make the prompt the main action on the chat screen.
- Keep fact review and generated-page preview easy to find.
- Use short Indonesian navigation labels while retaining clear accessible names.
- Preserve responsive layouts, keyboard focus, and reduced-motion support.
