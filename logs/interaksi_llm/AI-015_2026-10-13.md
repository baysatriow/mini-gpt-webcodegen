# AI-015: Spesifikasi halaman lengkap dan konteks 2.048

Pengguna menyetujui arah generasi bertahap, meminta efisiensi dan menanyakan apakah batas token dapat dinaikkan ke 2.048 karena contoh halaman membutuhkan sekitar 1.500 token.

Skill brainstorming dilanjutkan pada tahap arsitektur. Persetujuan arah mengizinkan penulisan spesifikasi. Dokumen tertulis perlu direview sebelum rencana implementasi menurut skill tersebut.

Source model menunjukkan learned position embedding 1.024 baris. Loader checkpoint dan lineage continuation menolak model_config berbeda. Karena itu konteks 2.048 membutuhkan migrasi weights-only yang eksplisit, inisialisasi posisi tambahan dan training; bukan mengganti konfigurasi kemudian exact resume. Tokenizer dan bobot proyek tetap dipertahankan dengan ancestry yang tercatat.

RUN-200 menghitung 393.216 parameter posisi tambahan atau 1,5 MiB bobot FP32, serta empat kali pasangan attention pada panjang penuh dengan batch sama. Ini perhitungan analitis, bukan profil GPU atau klaim penggunaan VRAM empat kali. Dua fixture manual muat di konteks 2.048 dan output budget 1.600, tetapi masih tidak muat di output budget 768.

Spesifikasi memilih konteks 2.048 dan runtime plan lalu section. Output tiap task dibatasi terpisah. Efisiensi berasal dari curriculum bertahap, length buckets, pengurangan padding, penggunaan data lokal, profil batch lebih kecil dan gradient accumulation jika diperlukan. Komposer dapat membentuk halaman lebih panjang daripada satu konteks model.

Spesifikasi mencakup kontrak PlanSpec/SectionSpec/PageSpec2, dispatch v1, data/provenance/family split, batas kegagalan/retry, renderer/media lokal, final baru, metrik isi/layout, browser acceptance, notebook dan log. Reviewed manusia tetap 12, final lama tetap consumed. Kontrak request terstruktur dibatasi sesuai curriculum; tidak mengklaim prompt bebas.

Dokumen: docs/superpowers/specs/2026-10-13-full-page-generation-design.md. Tidak mengubah kode produksi, mengunduh data atau menjalankan training pada tahap ini. LOG_TRAINING diberi catatan desain, bukan hasil TRAIN-016. Commit/push tetap pada branch pengembangan tanpa coauthor.
