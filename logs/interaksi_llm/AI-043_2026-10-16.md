# AI-043, penyederhanaan prompt dan intake website

- Tanggal: 16 Oktober 2026, zona waktu Asia/Jakarta.
- Permintaan pengguna: kurangi pertanyaan berulang saat melengkapi fakta halaman, izinkan prompting sederhana, dan redesain UI/UX agar lebih nyaman.
- Pemeriksaan source: UI mengirim draft kosong ke `/api/v1/intake/validate`, lalu menampilkan form wajib berisi nama, deskripsi, keunggulan, tiga layanan, tiga proses, serta tiga FAQ untuk landing page atau dua proyek untuk company profile. Form masih meminta jenis halaman, gaya, dan status usaha. Setelah form, pengguna melakukan validasi dan persetujuan ringkasan.
- Analisis model: konteks 2048 token; PagePlan menerima brief dan referensi fakta, SectionDraft memetakan referensi ke slot, lalu resolver lokal memasukkan nilai faktanya. Generator tidak menerima semua nilai fakta sebagai teks hari ini. Checkpoint belum dilatih untuk ekstraksi fakta dari prompt bebas. Batas prompt saat ini 1000 karakter. Model tidak menghasilkan HTML, CSS, atau JavaScript langsung. Prompt extractor berikutnya harus tunduk pada budget tokenizer setelah instruksi schema dan output JSON disisihkan.
- Rancangan draft: satu prompt; task ekstraksi RequestDraft dengan nilai yang disalin persis dari sumber lalu diverifikasi server sebagai substring brief; satu klarifikasi gabungan jika perlu; satu ringkasan dengan tombol Generate website; preview dan unduhan tetap memakai pipeline source-bound.
- Gerbang data: candidate extractor terpisah dari checkpoint generator TRAIN-025 step 1800. Development mengukur precision exact-value sedikitnya 95 persen, recall sedikitnya 90 persen, bukti source-bound, dan kelulusan gate generation yang ada. Final tetap tertutup.
- Status: dokumen desain menunggu review dan persetujuan pengguna. Belum mengubah kode, training, atau checkpoint. Final tetap tertutup.
