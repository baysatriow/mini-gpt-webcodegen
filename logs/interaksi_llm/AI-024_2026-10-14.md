# AI-024: Desain source-bound facts dan penanganan prompt, 14 Oktober 2026

## Permintaan

Pengguna menyetujui penulisan spesifikasi untuk kontrak yang merujuk fakta langsung ke request. Pengguna juga bertanya bagaimana sistem merespons prompt yang aneh dan keluaran yang akan diterima.

## Alasan

Raw output TRAIN-024 menunjukkan perubahan ejaan nama dan fakta pada plan serta section. Fakta sudah ada di request, tetapi kontrak saat ini meminta model mengulangnya. Untuk perbaikan yang deterministik, model perlu merujuk ID fakta dan renderer perlu mengambil nilai literal dari sumber request.

## Ringkasan desain

- PagePlan berisi urutan/role section, tipe komponen, variasi layout, asset ID, dan fact ID. Metadata genre, style, dan title berasal dari request.
- SectionDraft merujuk fakta alih-alih menyalin teks faktual. Renderer memvalidasi dan menyelesaikan referensi dari request; ini transformasi kontrak resmi, bukan perbaikan raw output.
- Prompt kosong atau kurang informasi wajib menghasilkan klarifikasi tanpa halaman. Request di luar cakupan menghasilkan penjelasan tanpa preview/download. Prompt terlalu panjang meminta ringkasan dan tidak dipangkas otomatis.
- Request valid yang lolos semua pemeriksaan menghasilkan preview sandbox dan file dari renderer. Raw error tetap internal. JavaScript bebas dari model tidak dieksekusi.
- Tema kreatif yang masih dapat dipetakan ke komponen proyek didukung. Permintaan luar cakupan tidak dijanjikan hasil parsial.

## Keputusan dan batas

- Dipilih: kontrak source-bound untuk eksperimen model berikutnya.
- Tidak dipilih: meneruskan keluaran faktual bebas model atau melonggarkan validator untuk mengejar angka 95 persen.
- Data dan bobot tetap tidak berubah. Dataset development tidak ditambahkan ke training. Final tetap tertutup.
- Spesifikasi disimpan pada `docs/superpowers/specs/2026-10-14-fullpage-source-bound-facts-design.md` untuk review pengguna sebelum rencana implementasi dibuat.
