# AI-041, tunnel demo terlindungi

- Tanggal: 16 Oktober 2026, zona waktu Asia/Jakarta.
- Permintaan: setelah generation lokal dan aplikasi siap, buka tunnel ngrok serta beri tahu pengguna.
- Persetujuan: pengguna menyetujui endpoint publik sementara dengan Basic Auth.
- Pelaksanaan: ngrok meneruskan Next.js pada loopback port 3000. FastAPI tetap pada loopback port 8000. Traffic Policy Basic Auth digunakan dan inspeksi request dinonaktifkan.
- Verifikasi: tanpa autentikasi, halaman utama mengembalikan 401. Dengan autentikasi, halaman utama serta health dan catalog API mengembalikan 200. FastAPI terkonfirmasi hanya mendengarkan pada loopback.
- Batas: tidak menjalankan generation atau inference tambahan, dan tidak melakukan uji beban. URL dan kredensial disampaikan langsung kepada pengguna, tidak disimpan pada repository.
