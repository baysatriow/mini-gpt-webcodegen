# AI-020: Eksperimen fullpage v3 dan diagnosis hasil

Pengguna meminta melanjutkan pembangunan model. Implementasi v3 yang sudah disepakati dijalankan untuk memperbaiki generasi halaman utuh landing page dan company profile, dengan target sekurangnya 76 dari 80 halaman development.

## Perubahan dan batas eksperimen

- Prompt plan diberi arahan ringkas untuk menyalin identitas permintaan secara tepat. Prompt section diberi batas agar hanya memakai fakta yang disediakan.
- Data sintetis hanya ditambahkan ke train: 960 halaman baru, 480 alias nama, 240 keluarga train yang sama, dan 5.760 task baru. Total data task train menjadi 23.040. Data validation dan test tetap sama checksum-nya dengan v2; final disalin dan di-hash tanpa diparse.
- Data belum ditinjau manusia. Schema, renderer, validator, batas konteks 2.048 token, output plan 512 token, dan output section 1.536 token dipertahankan.
- Manifest v3 SHA-256 `823d09401a92093d2e6dc463753074e9775d9591ce044185c3442adb07eeb8a6`. Manifest sumber v2 SHA-256 `b26f1714fa186081dec30c6f7c8ace478287601e0fc2bb318ae6f3601dbfd86d`.

## Profil GPU dan training

- RTX 5070 diuji pada effective batch 48. Batch mikro 8 dengan akumulasi 6 dipilih pada `FULLPAGE-GPU-004`, stabil pada sekitar 53.546 target token per detik dan peak reserved sekitar 2,29 GiB.
- Config membekukan 3.600 update, warmup 180, BF16, SDPA, fused AdamW, TF32, batch mikro 8, accumulation 6, checkpoint dan validasi setiap 600 update.
- TRAIN-020 dimulai fresh dari INIT2048 dan berhenti di update 1.800. Validasi CE 0,005813. Waktu training 568,70 detik, 29.424.126 target token. Snapshot generasi SHA-256 `0204941c5700d2f757c8a92537a2ffa7059d8e0ee4189338096a8991594032cf`.
- TRAIN-021 melanjutkan persis dari checkpoint TRAIN-020 hingga update 3.600. Validasi CE akhir 0,007596. Waktu training 557,89 detik, 58.756.012 target token kumulatif. Snapshot generasi SHA-256 `74ada927f75cb46ad6b4bc21ca2f3c5e725f76aee0d1e83902e832b1ba4e39a3`.

## Hasil development dan keputusan

- Baseline TRAIN-019: 70/80 halaman lengkap, CE 0,007519. Ambang 95 persen adalah 76/80.
- TRAIN-020: 0/80 halaman lengkap, 0/80 first attempt, CE 0,005813. Gate model gagal.
- TRAIN-021: 0/80 halaman lengkap, 0/80 first attempt, CE 0,007596. Gate model gagal.
- Tidak ada checkpoint v3 yang dipromosikan. Final benchmark tetap tidak dibuka. Review browser dan manusia belum dilakukan.
- Error terbesar adalah JSON atau kontrak rusak pada section `process`: 128 percobaan pada 64 halaman untuk update 1.800, lalu 144 percobaan pada 72 halaman untuk update 3.600. Kegagalan berikutnya termasuk title atau identitas tidak persis dan skema plan dengan field atau descriptor yang salah.
- Analisis komposisi data menunjukkan task `process` tetap 480 pada v2 maupun v3, sedangkan `navigation`, `services`, `faq`, `portfolio`, dan `footer` menerima tambahan. Ini sinyal yang perlu diuji, bukan bukti kausal.

## Koreksi dan debugging

- RUN-282 gagal kompilasi karena deklarasi `global ROOT` ditempatkan setelah referensi variabel. Letaknya diperbaiki; RUN-284 kompilasi berhasil.
- RUN-287 gagal pada utilitas PowerShell yang tidak tersedia. Sumber tetap utuh; salinan dan arsip kemudian diverifikasi SHA-256 pada RUN-288 dan RUN-289.
- RUN-290 berhenti karena sebagian prompt melampaui budget konteks 2.048 token. Audit RUN-291/292 menemukan pemicunya dan memilih instruksi fakta yang lebih pendek. Budget dan validator tidak dilonggarkan.
- RUN-303 salah membaca tingkat folder output sehingga audit awal tidak menemukan halaman. Penelusuran path diperbaiki pada RUN-304/305, lalu RUN-306/RUN-311 mengaudit hasil yang benar.
- RUN-312 mencoba membandingkan rasio sampler dari laporan yang salah. Laporan TRAIN-019 ditemukan pada RUN-313/314 dan RUN-315 memastikan baseline serta v3 sama-sama memakai `plan_batch_probability=0.7`. Karena itu v3 mengubah paparan role data, bukan rasio sampler. Notebook dan selection report memakai koreksi ini.
