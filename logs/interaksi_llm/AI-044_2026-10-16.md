# AI-044, revisi kontrak provenance dan evaluasi prompt-first

- Tanggal: 16 Oktober 2026, zona waktu Asia/Jakarta.
- Pemicu: review independen putaran keenam atas desain prompt-first menemukan ambiguitas pada pemetaan capability, atribusi fakta lintas pesan, dan denominator false-rejection.
- Revisi spesifikasi: capability didukung dipisahkan ke enum genre/style; hanya ID unsupported allowlist boleh masuk `RequestDraft.requested_features`; mention dinilai per kemunculan dan satu item request dibuat per ID.
- Provenance: request intake membawa pesan terstruktur dan format berversi. Server menetapkan segment map, memvalidasi nilai pada pesan sumber yang dirujuk, memetakan rentang Python ke UTF-16 untuk UI, dan memakai satu canonical prompt untuk validasi serta generation. Koreksi wajib cocok dengan tepat satu fakta lama dan membawa replacement serta cue pada pesan koreksi yang sama.
- Evaluasi: false-rejection didefinisikan per keluarga prompt unik dengan denominator known-catalog nonaktif, out-of-catalog nonaktif, dan unclear yang dilaporkan terpisah. Manifest beku mengaudit disjointness keluarga dan pola prompt terhadap TRAIN-025 dan seluruh partisi extractor.
- Status: menunggu review independen lanjutan dan persetujuan pengguna. Tidak mengubah aplikasi, API implementasi, model, atau checkpoint; tidak menjalankan inference/training. Final tetap tertutup.
