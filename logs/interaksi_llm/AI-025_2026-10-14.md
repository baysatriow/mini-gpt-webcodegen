# AI-025: Rencana implementasi source-bound fullpage, 14 Oktober 2026

## Permintaan

Setelah meninjau spesifikasi arsitektur source-bound facts, pengguna menyetujui untuk melanjutkan. Persetujuan ini mengizinkan penyusunan rencana implementasi untuk ditinjau, bukan langsung mengubah kode atau menjalankan training.

## Dasar rancangan

- TRAIN-024 menghasilkan 68 dari 80 halaman development, di bawah gate 76 dari 80. RUN-380 menemukan kesalahan ejaan nama dan fakta pada keluaran plan serta section.
- Spesifikasi memisahkan fakta sumber request dari pilihan struktur halaman model. Model memilih plan dan referensi, lalu resolver mengisi fakta literal dari request.
- Validator tetap ketat. Keluaran tidak menggunakan JavaScript bebas. UI, deployment, backend, browser review, dan final evaluation tetap di luar tahap ini.

## Rencana yang disiapkan

Rencana implementasi membagi pekerjaan menjadi sepuluh bagian: schema wire versioned; resolver dan komposer PageSpec 2.0; generasi source-bound beserta legacy dispatch; intake dan status klarifikasi/cakupan/budget; target sintetis train-only; lineage dan config dengan warm-start weights-only dari TRAIN-024 yang terpisah dari exact resume; pemilih checkpoint development; notebook proses; TRAIN-025 hingga update 1.800; serta exact resume TRAIN-026 hingga update 3.600 dan seleksi development.

Rencana mempertahankan split keluarga dan 80 request development yang sama. Rekaman test hanya di-hash sebagai bytes untuk bukti tidak berubah, tidak diparse menjadi contoh. Target tetap 76/80. Seluruh setting training dan optimasi GPU v4 selain perubahan kontrak, data, dan bobot awal dipertahankan. Notebook memuat tahapan supaya proses mudah diperiksa.

## Penyesuaian penting dari inspeksi kode

Runner saat ini mendukung exact resume, tetapi belum memiliki jalur weights-only warm-start dari checkpoint TRAIN-024. Rencana menambah jalur init eksplisit pada runner/engine: bobot model dimuat, sementara optimizer, scheduler, sampler, dan RNG dibuat baru. Resume TRAIN-026 tetap memulihkan seluruh state TRAIN-025.

Schema generation juga direncanakan menambah mode khusus source-bound agar default dan artefak schema legacy tetap tidak berubah. Export halaman dilakukan melalui staging, lalu dipindah setelah sukses agar tidak meninggalkan situs parsial.
