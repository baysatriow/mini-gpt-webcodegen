RUN-663: prompt-first fallback UI fix
Waktu: 17 Oktober 2026, 21:07, Asia/Jakarta

Masalah
- API ekstraksi yang aktif mengembalikan 503 `extractor_unavailable` karena belum ada kandidat extractor di paket seleksi.
- UI lama menerjemahkan kondisi fail-closed yang diketahui menjadi kartu error merah dan form manual penuh.

Perubahan
- `apps/web/src/components/chat/chat-shell.tsx` menangani 503 `extractor_unavailable` secara khusus.
- UI meminta `/api/v1/intake/validate` menurunkan field yang belum tersedia dari request draft kosong, lalu menampilkan satu form klarifikasi tanpa error merah.
- Form meminta fakta lengkap yang bisa diisi. Tidak ada nama, layanan, proses, atau FAQ yang direka oleh aplikasi.
- Label agregat `request_draft` tidak ditampilkan karena tidak memiliki kontrol form tersendiri. Kontrak API dan validasinya tidak diubah.
- Jika validasi fallback juga gagal, UI mempertahankan jalur error sebelumnya.
