User-facing decision

- Keep all required facts for a complete landing page or company profile.
- Let the user submit one free-form brief, then ask for all missing facts together.
- Preserve source evidence, conflict handling, an explicit status choice, and an explicit Generate action.
- Keep automatic extraction disabled until a separate checkpoint passes the frozen development gate.

Preflight and failed attempts

1. Initial direct invocation `python qa/prepare_request_extract_v1.py` failed with `ModuleNotFoundError: No module named 'src'`. No dataset was created. Use module invocation from the project root.
2. Module invocation with a single complete output found an example requiring 1,221 prefix tokens and 1,723 target tokens. The 2,944-token total cannot fit the 2,048-token context. No dataset was created.
3. The first scoped target pass found a correction phrase longer than the schema's 240-character limit. The target now stores only the exact correction cue phrase, while old and replacement values remain separate and source-checked.
4. A combined services scope exceeded context on a long correction example. Services and processes were split by item position; FAQ and project scopes are also per item. The final request has 16 fixed internal scopes.
5. The first per-item validator attempt applied the item index twice and rejected `service_2`. Validation now checks that a per-item scope has at most one fact of the expected kind without slicing its output again. No dataset was written by this failed preflight.

Scope and limitations

- Up to 16 sequential internal decodes may be required per API request. This latency has not been measured on the RTX 5070 and must be measured before promotion.
- The corpus is synthetic where noted and has not received human review. Audit success proves schema, lineage, exact source substrings, disjoint families/patterns, and token budgets. It does not prove model extraction quality.
- No training, inference, automated test suite, generation, checkpoint selection, or final/test data access occurred.
- Data and audit artifacts stay local and are ignored by Git. The notebook redacts the displayed example and has no training output yet.
