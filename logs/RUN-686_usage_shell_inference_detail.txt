Tujuan
Menerapkan rancangan comp-first untuk navigasi bersama, workspace Usage, dan detail audit inference bagi tim VibeStack.

Implementasi
- HistorySidebar dipakai bersama oleh Chat dan Usage. Pada desktop sidebar tetap terlihat; pada layar kecil navigasi terbuka sebagai drawer.
- Usage memiliki ringkasan request dan GPU, pencarian server-side prompt/fakta, filter status/tahap/periode, riwayat run, dan detail terpilih.
- Detail memuat input/fakta bila API menyediakan field audit, rail lima tahap, event aktual, status, source accepted, metrik GPU seluruh perangkat, dan metrik PyTorch proses model.
- Source dibaca hanya dari endpoint generation yang diterima renderer dan dirender sebagai teks. Tidak ada eksekusi source di halaman audit.
- Kompatibilitas terhadap API lama menampilkan penjelasan saat prompt/fakta belum dikembalikan. Reselect run yang sama memuat detail kembali. Header detail duplikat dihapus. Pesan ruang lingkup GPU API lama diterjemahkan ke bahasa Indonesia.
- README produk dan status spesifikasi diperbarui. Retensi lokal 90 hari dan batas privasi mengikuti rancangan yang disetujui.
