# Contoh input generator

Prompt di folder prompts adalah input demonstrasi dengan pola katalog yang dilatih. Semua bisnis fiktif; tidak memuat kontak pribadi. Studio Cakrawala adalah probe development yang pernah gagal pada model v2. Kafe Senandika disiapkan untuk mencoba CSS Tailwind, font serif dan tabs pada model lanjutan.

Prompt tidak otomatis menjadi bukti model berhasil. Lihat status dan raw output aktual di [laporan pengembangan](../reports/OUTPUT_DEVELOPMENT_2026-10-13.md). Bila validator menolak, file mentah disimpan tanpa memperbaiki nama atau menambahkan target ke HTML.

Lihat [panduan generasi](../docs/GENERATING_WEBSITES.md) untuk menjalankan input dengan checkpoint dan evidence yang sesuai. Buat folder output baru setiap percobaan.
